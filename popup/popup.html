How to use:
  1. Open chatgpt.com and wait for the sidebar to load.
  2. Checkboxes appear next to each conversation.
  3. Use the floating panel (or sidebar controls) to Select All / Filter / Delete.
  4. Deleting drives the native ChatGPT UI — no tokens extracted.
Troubleshooting
  • If checkboxes don't appear: click Rescan or scroll the sidebar, then refresh.
  • If Delete fails: ChatGPT changed its UI — see README debugging.
  • Filtered view only hides in-extension; ChatGPT search unchanged.
